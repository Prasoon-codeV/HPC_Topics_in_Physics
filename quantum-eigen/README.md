# Quantum Eigenvalue Solver

The Quantum Eigenvalue solver calculates the Energy Eigenvalues for the N^2 space. It covers the cases of potential well and harmonic. It can be further extended for the other working examples as well. 

File Organization:

1. `src/eigen.py` - Python file containing the solver function and outputs energy eigenvalues in ascending order.
2. `tests/test_simple.py` - Contains the initial tester code for verifying performance of  `src/eigen.py`.
